
# Registro de uso de Inteligencia Artificial

## TPI - Metodología de Sistemas II

### 1. Herramienta utilizada

Se utilizó ChatGPT de OpenAI como herramienta de asistencia durante el desarrollo del Trabajo Práctico Integrador.

### 2. Finalidad

La inteligencia artificial se utilizó para:

- Interpretar los requisitos de la consigna.
- Analizar el sistema existente.
- Identificar problemas de calidad y deuda técnica.
- Proponer refactorings y fragmentos de código.
- Elaborar y ampliar pruebas con JUnit.
- Analizar errores durante las pruebas.
- Colaborar con la documentación técnica.
- Organizar las evidencias y el trabajo en Git.

### 3. Registro de interacciones relevantes

#### Interacción 1 - Organización del trabajo

Consulta sobre cómo demostrar el antes y el después mediante commits y tags de Git.

Resultado: organización del repositorio para conservar las versiones del sistema.

#### Interacción 2 - Diagnóstico técnico

Análisis de archivos del sistema Gestión de Pedidos y capturas de código.

Resultado: identificación y documentación de ocho problemas técnicos.

#### Interacción 3 - Refactoring

Solicitud de orientación para aplicar Extract Method, simplificación de métodos, reubicación de responsabilidades e Introduce Parameter Object.

Resultado: implementación de cuatro refactorings.

#### Interacción 4 - Pruebas automatizadas

Asistencia para crear y ejecutar pruebas con JUnit.

Resultado: incorporación de pruebas para cálculos de pedidos y persistencia.

#### Interacción 5 - Detección de defectos

Se compartió un resultado de prueba que esperaba 9000.0 y obtenía 5000.0.

Resultado: análisis del problema de igualdad en DetallePedido, corrección del código y ejecución satisfactoria de la prueba de regresión.

#### Interacción 6 - Documentación

Asistencia para organizar el diagnóstico, el checklist de code review, las evidencias y el README.

Resultado: elaboración de la documentación técnica del proyecto.

### 4. Intervención humana

La IA proporcionó explicaciones, propuestas de código y borradores de documentación.

Los cambios fueron incorporados al proyecto y las pruebas fueron ejecutadas por el estudiante mediante IntelliJ IDEA y Gradle.

Las propuestas se contrastaron con el funcionamiento observado y los resultados de las pruebas.

### 5. Limitaciones

Las respuestas de IA pueden contener errores o recomendaciones que requieren adaptación.

Por este motivo, se utilizaron pruebas automatizadas, revisión del código y evidencias de ejecución para verificar los cambios realizados.

### 6. Evidencias

Este documento resume las interacciones principales, pero no constituye una transcripción literal completa de los prompts.

Las conversaciones relevantes con ChatGPT deberán conservarse en el anexo de evidencias para permitir la revisión del proceso.
